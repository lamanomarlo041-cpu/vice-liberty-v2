# Règlement ViceLiberty V2

Site statique prêt pour GitHub et Vercel.

## Déploiement sur Vercel

1. Crée un dépôt GitHub.
2. Ajoute tous les fichiers de ce dossier dans le dépôt.
3. Va sur Vercel.
4. Clique sur **Add New Project**.
5. Importe ton dépôt GitHub.
6. Clique sur **Deploy**.

Le site utilise `index.html` comme page principale.
